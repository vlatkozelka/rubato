# Return Policy

_Last updated: 2026-08-10_

## Standard return window

Most items purchased from our store may be returned within **30 days of the
delivery date** for a full refund to the original payment method, provided the
item is unused, unworn, and in its original packaging with tags attached.

## Electronics

Electronics (earbuds, fitness trackers, speakers, reading lights, and similar
items) have a shortened return window of **14 days from the delivery date**
due to higher depreciation and restocking costs. This applies to items that
are working as intended but no longer wanted. Electronics that are defective
or malfunctioning are covered under warranty instead — see the Warranty
document for defect timelines, which supersede this 14-day window for defect
claims specifically.

## Defective or damaged items

Defective or damaged items of any category are handled as **warranty claims,
not standard returns**. See the Warranty document for coverage windows and
process. This document's 30-day and 14-day windows apply only to
change-of-mind returns of non-defective items; they do not apply when the
item is defective.

## Opened software

Software license cards, activation codes, and digital-good redemption cards
are **final sale once opened or the code has been revealed**. No returns or
refunds are issued on opened software under any circumstances, defective or
not, since the code cannot be resold or re-issued. This is the one category
where the warranty document's defect coverage does not apply — see Warranty
for the explicit carve-out.

## Return shipping

Return shipping is **free** for orders with an original order total of **$75
or more**. For orders under $75, a flat $6.00 return shipping fee is deducted
from the refund unless the return is due to a defect or a fulfillment error on
our part, in which case return shipping is always free per the Warranty
document.

## Return abuse

We reserve the right to review accounts with unusually frequent returns.
Customers with **3 or more "changed mind" returns within a rolling 60-day
window** may be limited to store credit instead of a refund to the original
payment method, at the discretion of a support agent. Warranty claims never
count toward this threshold — see Warranty for why.

## How to start a return

Returns can be initiated from the order history page or through support chat.
Once a return is approved, a prepaid shipping label is emailed within 24
hours. Refunds are issued within 5-7 business days of the returned item
arriving at our warehouse.
