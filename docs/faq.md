# Frequently Asked Questions

## Can I combine a discount code with a sale price?

No. Only one discount code can be applied per order, and discount codes
cannot be combined with items already marked down for a site-wide sale.

## Do you offer price adjustments if an item goes on sale after I buy it?

Yes, within 7 days of your order date. Contact support with your order number
and we will refund the difference to your original payment method.

## Can I return a gift without a receipt?

Yes. Gift returns are accepted within the standard return window measured
from the delivery date, and are issued as store credit rather than a refund
to a payment method, since we don't have the original payment details.

## What sizes do jackets and sweaters run?

Outerwear and sweaters run true to size based on standard US sizing. If
you're between sizes, we generally recommend sizing up for outerwear meant to
be layered over other clothing.

## How do I check if an item is back in stock?

Product pages show current stock levels. We don't offer back-in-stock email
alerts at this time; checking the product page periodically is the only way
to confirm restocking.

## Can I change the size or color after placing an order?

Only if the order has not yet entered processing. After that, the order would
need to be returned or exchanged once delivered, following the standard
return policy.

## Is there a loyalty or VIP program?

Yes. VIP-tier customers receive free expedited shipping on all orders and
priority handling on support requests, including approval-gated requests like
refunds.
